## Система оценивания

<!-- [Презентация с правилами оценивания](./slides/intro/ML_grading_system.pdf) -->

Презентация с правилами оценивания (TODO)


| Уровень владения | Зачет (осень) | Начинающий (3, весна) | Средний (4, весна) | Продвинутый (5, весна)             |
| ---------------- | ------------- | --------------------- | ------------------ | ---------------------------------- |
| **Активность**   |               |                       |                    |                                    |
| Base labs        | 5             | 5                     | 5                  | 5                                  |
| Research labs    | 0             | 0                     | 4                  | 5                                  |
| Коллоквиум       | 3             | 3                     | 4                  | 5                                  |
| Экспресс-тесты   | 3             | 3                     | 4                  | 5                                  |
| Взвешенная сумма | 4             | 4                     | 6                  | 8                                  |
| Экзамен          | -             | -                     | -                  | 5 <br> по системе "сдать/не сдать" |

Взвешенная сумма вычисляется по формуле
$$
\text{Взвешенная сумма} = \begin{cases}
    0.5 \cdot \text{Research labs} + 0.3 \cdot \text{Коллоквиум} + 0.2 \cdot \text{Экспресс-тесты}, & \text{Если поток} = 1, 3 \\
    0.5 \cdot \text{Research labs} + 0.5 \cdot \text{Коллоквиум}, & \text{Если поток} = 2 \\
\end{cases}
$$

> Примечание: Правила оценивания могут измениться в ближайшую неделю. Ожидайте публикации презентации с правилами оценивания

> Примечание: В таблице указаны пороги для сданных в срок заданий. В [презентации](./slides/intro/ML_grading_system.pdf) описаны SOS-случаи, позволяющие добрать баллы в конце семестра, и пороги для них.
